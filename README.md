# 智能戒指 Google Billing 与后台集成演示

本项目是一个基于 `React + Vite + TypeScript` 构建的演示应用，专门用于展示如何集成 Google Billing Library（安卓端）的订阅/支付逻辑，并将生成的订单安全地持久化到 Google Sheets 表格中。

---

## 📦 安装与本地启动

请确保您已安装 [Node.js](https://nodejs.org/) (推荐 v18+)。在项目根目录（`google-billing-demo`）执行以下命令：

```bash
# 1. 安装项目依赖
npm install

# 2. 启动本地开发服务器
npm run dev
```

启动后，在浏览器中访问终端输出的本地地址（通常为 `http://localhost:5173`）即可预览交互。

## 📊 步骤一：Google Sheets 配置指南

我们需要创建一个用于储存套餐信息和接受订单的数据库。

1. **新建表格**：前往 [Google Sheets](https://docs.google.com/spreadsheets)，新建一个空白表格（可命名为“智能戒指会员系统”）。
2. **创建工作表**：在页面底部，创建两个工作表（Sheet），确保命名完全一致：
   - 命名为：`套餐`
   - 命名为：`订单`
3. **设置表头**：
   - 在 `订单` 工作表的第一行分别填入以下表头 (A1, B1, C1)：**订单 ID**, **产品 ID**, **订单信息**
   - 在 `套餐` 工作表的第一行分别填入以下表头 (A1, B1, C1, D1)：**产品 ID**, **产品标题**, **产品价格**, **产品描述**

## 🚀 步骤二：Google Apps Script (GAS) 部署指南

通过 Google Apps Script，我们可以将上面的表格转换成 RESTful API，供前端页面或 App 调用。

1. **打开 Apps 脚本编辑器**：
   - 在刚刚创建好的 Google Sheets 的顶部菜单栏中，点击 `扩展程序` -> `Apps脚本`。
2. **植入后台代码**：
   - 清空编辑器中原有的 `myFunction` 代码。
   - 打开本项目根目录下的 `GAS_Script.gs` 文件，将其中的所有代码复制并粘贴到在线编辑器中。
   - 点击保存（Ctrl+S 或 Cmd+S）。
3. **发布 Web 应用**：
   - 点击右上角的 `部署` -> `新建部署`。
   - 点击左侧的齿轮图标 ⚙️，选择 `Web 应用`。
   - **执行身份**：选择 `我`。
   - **访问权限**：必须选择 `所有人`。
   - 点击 `部署`，进行 Google 账号首次运行授权（选择高级 -> 转至不安全的页面 -> 允许）。
   - 最后复制生成的 **Web 应用网址 (Web app URL)**。

---

## 🔗 步骤三：连接您的 React 项目

1. 返回本项目的根目录，找到 `.env` 文件。
2. 将 `VITE_GOOGLE_APP_SCRIPT_URL` 的值替换为您在上面刚刚复制的 Web app URL，例如：
   ```env
   VITE_GOOGLE_APP_SCRIPT_URL=https://script.google.com/macros/s/AKfycb.../exec
   ```
3. 重新启动你的终端 `npm run dev`，前端页面就会完全同步显示您的智能戒指真实套餐！点击订阅后，在 `订单` 工作表中也能实时看到新增的数据。
